# Compose Canvas Demo

A small Android demo showing custom 2D rendering and interaction using Jetpack Compose Canvas.

## Features
- Tap to place nodes
- Drag nodes to reposition them
- Dynamic line connections between nearby nodes
- State-driven rendering using Jetpack Compose

## Tech
- Kotlin
- Jetpack Compose
- Compose Canvas

## Why this sample
I created this focused sample to demonstrate hands-on experience with custom drawing, pointer interaction, coordinate-based rendering, and state-driven UI updates on Android.
